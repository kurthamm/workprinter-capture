# Movie Stuff

New capture software for the MovieStuff **WorkPrinter XP** 8mm film transfer machine, replacing the obsolete CineCap program.

## What it will do

1. Pick which WorkPrinter you're using (profiles for two machines).
2. Press Capture and run the reel. The XP's frame switch triggers the camera once per frame, and every frame is saved.
3. Press Create Movie to get a video file at 16, 18, 24 fps or a custom speed.

## Setup

- WorkPrinter XP (existing hardware, unchanged)
- Windows 11 PC or laptop with USB
- A modern USB camera with global shutter and trigger input (see `DECISIONS.md`, section 5)
- This software
