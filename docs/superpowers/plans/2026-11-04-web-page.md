# Web Page and Service Implementation Plan (plan 2 of 4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the capture core into a running program: a background service that owns one or more machines (simulated for now, real hardware in plans 3 and 4), with an HTTPS, password-protected web page the operator runs a scan from (Ready / Recording / STOP, live picture, counts, New Reel / Stop / Resume, delay calibration), alerts in the browser (color, sound, notification) and on the phone (ntfy), and crash recovery at startup.

**Architecture:** One process. A `Service` builds each machine from a TOML config and runs it on its own thread through a `Runner` (this plan ships `SimRunner`, which drives a `SimRig` in real time; plans 3 and 4 add a runner for a serial sync box and a Media Foundation camera behind the same interface). Every machine's `Alerter` is an `AlertBus` that keeps recent alerts, fans them out to web clients (server-sent events) and forwards to `ntfy` when configured. FastAPI serves a single static page (plain HTML, CSS and JavaScript, no build step) and a small JSON API; the page gets status pushes every half second and alert pushes immediately. Pictures reach the page as JPEG snapshots made on demand from the machine's latest picture and last saved frame.

**Tech Stack:** Python 3.12, `uv`, `pytest`, `ruff`, `numpy`, `Pillow` (existing); new: `fastapi`, `uvicorn`, `cryptography` (local certificate), `psutil` (PC temperature where the OS exposes it); dev: `httpx` (FastAPI test client). Standard library for TOML (`tomllib`), password hashing (`hashlib.scrypt`), cookie signing (`hmac`), ntfy posting (`urllib.request`).

**Spec:** `docs/superpowers/specs/2026-09-23-workprinter-capture-design.md` (revision 4). Sections implemented here: 5.4 (calibration of the delay), 5.6 (two machines, one computer: two sim machines in one service), 6.1–6.5 (operation: the page, alerts), 7.2 (recovery wired at startup), 9.1 (web page, alerts, Demo Mode), 9.2 (HTTPS, password), 10.1 (the simulator tests that need the page: two machines at once, fault on one does not affect the other).

**Out of scope here (plan 2b, next):** Review (step through frames, flags, crop/rotation), Create Movie (FFmpeg presets), join reels, order deliverable, delete frames after delivery, resume overlap trimming, neighbour keeping, auto-MP4 on reel finish. Plan 3: firmware in C and the serial runner. Plan 4: Windows camera backend, installer as a Windows service, bundled FFmpeg, setup guide.

## Global Constraints

- Python **3.12** (`requires-python = ">=3.12"`); run everything through `uv`.
- Canonical verification command is `testrepo`, which runs `make test` (ruff + pytest). Every task ends with `testrepo` passing.
- Fail fast: no default values that mask missing config, no swallowed exceptions, no stubs, no fake data in production paths (global CLAUDE.md). A missing or wrong config field stops the program at startup with a message naming the field. The one deliberate exception, ruled here: a failure to **deliver** an alert (ntfy unreachable, browser gone) is reported as a warning on the alert bus and never raises into capture, because capture must outlive the page (spec 9.1 "a slow page never costs a frame").
- **Capture never waits on the page.** Web handlers only read machine state under the machine's lock for microseconds (`status()`, picture snapshots); JPEG encoding happens on the web thread from a copied array. No handler calls anything that blocks on the saver.
- **Accounting rule (spec 7.2)** stays in force: the page shows `clicks`, `saved`, `pending`, `failed` straight from `MachineStatus`; nothing is recomputed in the web layer.
- The page is **HTTPS only**, password protected (spec 9.2). HTTP never serves anything but a redirect. The password is stored as an scrypt hash in the config, never in clear.
- Home network only (spec 9.2): the server binds to the configured address; the default sample config binds `0.0.0.0` on port `8443` and the setup guide says the router must not forward it.
- Machine names are unique within a config and valid reel-folder prefixes (`ReelFolder.check_name`).
- Alerts have exactly three levels: `info`, `warning`, `problem` (as `RecordingAlerter` enforces). Problems are the red STOP state: a loud repeating alarm on the page until acknowledged.
- Git: branch `feature/web-page` from `main`; one commit per task; PR + CodeRabbit before user testing.
- Pictures are `numpy.ndarray` `(H, W, 3)` `uint8` RGB; PC times in nanoseconds (`perf_counter_ns` domain); sync-box times in microseconds.

## Review Focus

1. **Wrong password, many times** (a child, a scanner on the LAN). Expected: every attempt costs the caller a one-second delay, the comparison is constant time, nothing is logged in clear, and the right password still works afterwards. Test in Task 7 (`test_wrong_password_is_slow_and_rejected`).
2. **The operator closes the browser mid-reel, or the Wi-Fi drops.** Expected: the scan is unaffected; the alert bus does not grow without bound; when the page comes back it shows the current state and the alerts it missed. Test in Task 4 (`test_subscriber_queue_is_bounded_and_dropped_on_close`) and Task 10 (`test_scan_continues_with_no_web_client`).
3. **A reel drive is missing at startup** (USB drive not plugged in, config typo). Expected: the service refuses to start with a message naming the machine and the path; it does not create the folder on the wrong disk. Test in Task 6 (`test_missing_reel_root_stops_startup`).
4. **New Reel with a name Windows cannot create** (`CON`, trailing dot, `?`). Expected: HTTP 400 with the reason, the current reel untouched, the machine state unchanged. Test in Task 7 (`test_new_reel_bad_name_is_400`).
5. **Two machines in the config with the same name, or the same reel root.** Expected: refused at startup with both names in the message, because two machines writing into one reel root would collide on default reel names. Test in Task 3 (`test_duplicate_machine_names_rejected`, `test_shared_reel_root_rejected`).

```python
    def window(self, t_ns: int, before: int, after: int) -> list[Picture]:
        """The picture nearest t_ns with up to `before` older and `after` newer neighbours,
        oldest first. Fewer at the edges of the buffer; empty when the buffer is empty."""
        if not self._pics:
            return []
        pics = list(self._pics)
        centre = min(range(len(pics)), key=lambda i: abs(pics[i].t_ns - t_ns))
        return pics[max(0, centre - before) : centre + after + 1]
```

```python
    # ---- pictures for the page --------------------------------------------------------------

    def live_picture(self) -> Picture | None:
        with self._lock:
            return self._live

    def last_saved(self) -> tuple[int, Picture] | None:
        with self._lock:
            return self._last_saved

    def click_window(self, before: int = 3, after: int = 3) -> list[tuple[int, Picture]]:
        """Pictures around the last click's target time, with their offset in ms (rounded)."""
        with self._lock:
            target = self._picker.last_target_ns
            if target is None:
                return []
            return [(round((p.t_ns - target) / 1e6), p) for p in self._picker.window(before, after)]

    def set_delay_ms(self, delay_ms: float) -> None:
        """Calibration: the delay from switch closure to the sharp picture. Not while recording
        (frames in flight were picked with the old delay). Recorded in the open reel."""
        if not (0.0 <= delay_ms <= 500.0):  # also rejects NaN
            raise ValueError(f"delay must be 0..500 ms, got {delay_ms}")
        with self._event():
            if self.state == MachineState.RECORDING:
                raise RuntimeError("cannot change the delay while recording: Stop first")
            self.config.delay_ms = delay_ms
            self._picker.set_delay(round(delay_ms * 1e6))
            if self.reel is not None:
                data = self.reel.read_reel_json()
                data["delay_ms"] = delay_ms
                self.reel.write_reel_json(data)
```

```python
"""wpcap.toml: the one configuration file. Every field is required unless stated; a missing
or wrong field stops the program at startup with a message naming it (fail fast)."""

from __future__ import annotations

import hashlib
import hmac
import secrets
import tomllib
from dataclasses import dataclass
from pathlib import Path

from wpcap.reel import ReelFolder

FILM_TYPES = ("super8", "regular8")
MACHINE_KINDS = ("sim",)  # plans 3 and 4 add "serial"
_SERVER_KEYS = {"host", "port", "password_hash", "secret", "cert_file", "key_file"}
_MACHINE_KEYS = {"name", "kind", "reel_root", "delay_ms", "debounce_us", "film_type", "sim_frames"}
_NTFY_KEYS = {"url", "topic"}


class ConfigError(Exception):
    pass


@dataclass(frozen=True)
class ServerConfig:
    host: str
    port: int
    password_hash: str
    secret: str
    cert_file: Path
    key_file: Path


@dataclass(frozen=True)
class NtfyConfig:
    url: str
    topic: str


@dataclass(frozen=True)
class MachineSpec:
    name: str
    kind: str
    reel_root: Path
    delay_ms: float
    debounce_us: int
    film_type: str
    sim_frames: int


@dataclass(frozen=True)
class AppConfig:
    server: ServerConfig
    machines: list[MachineSpec]
    ntfy: NtfyConfig | None


# ---- passwords -----------------------------------------------------------------------------

_SCRYPT = dict(n=2**14, r=8, p=1, dklen=32)


def hash_password(password: str) -> str:
    salt = secrets.token_bytes(16)
    key = hashlib.scrypt(password.encode("utf-8"), salt=salt, **_SCRYPT)
    return f"scrypt${salt.hex()}${key.hex()}"


def verify_password(password: str, stored: str) -> bool:
    """Constant-time; a malformed stored value is simply 'no match'."""
    try:
        algo, salt_hex, key_hex = stored.split("$")
        if algo != "scrypt":
            return False
        salt, key = bytes.fromhex(salt_hex), bytes.fromhex(key_hex)
    except ValueError:
        return False
    if len(key) != _SCRYPT["dklen"]:
        return False
    candidate = hashlib.scrypt(password.encode("utf-8"), salt=salt, **_SCRYPT)
    return hmac.compare_digest(candidate, key)


def new_secret() -> str:
    return secrets.token_hex(32)


# ---- loading -------------------------------------------------------------------------------


def _section(data: dict, name: str, keys: set[str]) -> dict:
    sec = data.get(name)
    if not isinstance(sec, dict):
        raise ConfigError(f"missing [{name}] section")
    unknown = set(sec) - keys
    if unknown:
        raise ConfigError(f"unknown key(s) in [{name}]: {', '.join(sorted(unknown))}")
    missing = keys - set(sec)
    if missing:
        raise ConfigError(f"missing {name}.{sorted(missing)[0]}")
    return sec


def _typed(sec: dict, where: str, key: str, typ: type) -> object:
    v = sec[key]
    if typ is float and isinstance(v, int) and not isinstance(v, bool):
        v = float(v)
    if not isinstance(v, typ) or isinstance(v, bool):
        raise ConfigError(f"{where}.{key} must be {typ.__name__}, got {v!r}")
    return v


def _server(data: dict) -> ServerConfig:
    s = _section(data, "server", _SERVER_KEYS)
    port = _typed(s, "server", "port", int)
    if not 1 <= port <= 65535:
        raise ConfigError(f"server.port out of range: {port}")
    for k in ("host", "password_hash", "secret", "cert_file", "key_file"):
        _typed(s, "server", k, str)
    if not s["password_hash"].startswith("scrypt$"):
        raise ConfigError("server.password_hash is not an scrypt hash (run: wpcap hash-password)")
    if len(s["secret"]) < 32:
        raise ConfigError("server.secret must be at least 32 characters (run: wpcap init-config)")
    return ServerConfig(
        host=s["host"],
        port=port,
        password_hash=s["password_hash"],
        secret=s["secret"],
        cert_file=Path(s["cert_file"]),
        key_file=Path(s["key_file"]),
    )


def _ntfy(data: dict) -> NtfyConfig | None:
    if "ntfy" not in data:
        return None
    n = _section(data, "ntfy", _NTFY_KEYS)
    _typed(n, "ntfy", "url", str)
    _typed(n, "ntfy", "topic", str)
    if not n["url"].startswith(("http://", "https://")):
        raise ConfigError(f"ntfy.url must start with http:// or https://, got {n['url']!r}")
    return NtfyConfig(url=n["url"].rstrip("/"), topic=n["topic"])


def _machine(i: int, m: object) -> MachineSpec:
    where = f"machine[{i}]"
    if not isinstance(m, dict):
        raise ConfigError(f"{where} must be a table")
    unknown = set(m) - _MACHINE_KEYS
    if unknown:
        raise ConfigError(f"unknown key(s) in {where}: {', '.join(sorted(unknown))}")
    missing = _MACHINE_KEYS - set(m)
    if missing:
        raise ConfigError(f"missing {where}.{sorted(missing)[0]}")
    name = _typed(m, where, "name", str)
    try:
        ReelFolder.check_name(name)
    except ValueError as e:
        raise ConfigError(f"{where}.name: {e}") from e
    kind = _typed(m, where, "kind", str)
    if kind not in MACHINE_KINDS:
        raise ConfigError(f"{where}.kind must be one of {MACHINE_KINDS}, got {kind!r}")
    film_type = _typed(m, where, "film_type", str)
    if film_type not in FILM_TYPES:
        raise ConfigError(f"{where}.film_type must be one of {FILM_TYPES}, got {film_type!r}")
    delay_ms = _typed(m, where, "delay_ms", float)
    if not 0.0 <= delay_ms <= 500.0:
        raise ConfigError(f"{where}.delay_ms must be 0..500")
    debounce_us = _typed(m, where, "debounce_us", int)
    if not 1000 <= debounce_us <= 100_000:
        raise ConfigError(f"{where}.debounce_us must be 1000..100000")
    sim_frames = _typed(m, where, "sim_frames", int)
    if sim_frames < 1:
        raise ConfigError(f"{where}.sim_frames must be at least 1")
    return MachineSpec(
        name=name,
        kind=kind,
        reel_root=Path(_typed(m, where, "reel_root", str)),
        delay_ms=delay_ms,
        debounce_us=debounce_us,
        film_type=film_type,
        sim_frames=sim_frames,
    )


def load_config(path: Path) -> AppConfig:
    try:
        data = tomllib.loads(path.read_text(encoding="utf-8"))
    except FileNotFoundError as e:
        raise ConfigError(f"config file not found: {path}") from e
    except tomllib.TOMLDecodeError as e:
        raise ConfigError(f"{path}: {e}") from e
    unknown = set(data) - {"server", "ntfy", "machine"}
    if unknown:
        raise ConfigError(f"unknown top-level key(s): {', '.join(sorted(unknown))}")
    server = _server(data)
    ntfy = _ntfy(data)
    raw = data.get("machine")
    if not isinstance(raw, list) or not raw:
        raise ConfigError("at least one [[machine]] is required")
    machines = [_machine(i, m) for i, m in enumerate(raw)]
    names = [m.name for m in machines]
    for n in names:
        if names.count(n) > 1:
            raise ConfigError(f"machine name used twice: {n!r}")
    roots = [m.reel_root.resolve() for m in machines]
    for i, r in enumerate(roots):
        if roots.index(r) != i:
            raise ConfigError(
                f"reel_root shared by {machines[roots.index(r)].name!r} and {machines[i].name!r}: "
                "each machine needs its own reel folder"
            )
    return AppConfig(server=server, machines=machines, ntfy=ntfy)
```

**Files:**
- Create: `src/wpcap/alerts.py`
- Test: `tests/test_alerts.py`

**Interfaces:**
- Consumes: `wpcap.machine.Alerter` protocol (`alert(level, title, message)`), `NtfyConfig`
- Produces:
  - `Alert(level, title, message, t: float, machine: str, id: int)` frozen dataclass; `as_dict()`.
  - `AlertBus(forward: Alerter | None = None, keep: int = 200)`: `for_machine(name) -> Alerter` (a bound alerter that stamps the machine name), `recent(limit: int = 50) -> list[Alert]` (newest last), `subscribe() -> Subscription`, `subscribers: int`.
  - `Subscription.get(timeout: float) -> Alert | None`, `Subscription.close()`; its queue holds at most 100 alerts; when full the oldest is dropped and a counter `dropped` incremented (the page will refetch `recent` on reconnect anyway).
  - `NtfyAlerter(cfg: NtfyConfig, timeout_s: float = 3.0)`: `alert(level, title, message)` POSTs to `{url}/{topic}` with headers `Title`, `Priority` (`problem` → `urgent`, `warning` → `high`, `info` → `default`), `Tags` (`rotating_light` / `warning` / `white_check_mark`); on any failure raises `NtfyError`.
  - The bus forwards every alert to `forward` **after** storing it and waking subscribers; a `NtfyError` (or any `Exception`) from `forward` becomes one `warning` alert on the bus itself, titled `"Phone alert failed"`, at most once per 60 s (so a dead ntfy server does not flood the page).

```python
"""Alerts: one bus per process. Machines call alert(); the page and ntfy listen."""

from __future__ import annotations

import json
import queue
import threading
import time
import urllib.error
import urllib.request
from collections import deque
from dataclasses import asdict, dataclass

from wpcap.config import NtfyConfig
from wpcap.machine import Alerter

LEVELS = ("info", "warning", "problem")
_PRIORITY = {"problem": "urgent", "warning": "high", "info": "default"}
_TAGS = {"problem": "rotating_light", "warning": "warning", "info": "white_check_mark"}


@dataclass(frozen=True)
class Alert:
    level: str
    title: str
    message: str
    t: float  # time.time()
    machine: str
    id: int

    def as_dict(self) -> dict:
        return asdict(self)


class NtfyError(Exception):
    pass


class NtfyAlerter:
    def __init__(self, cfg: NtfyConfig, timeout_s: float = 3.0) -> None:
        self._url = f"{cfg.url}/{cfg.topic}"
        self._timeout = timeout_s

    def alert(self, level: str, title: str, message: str) -> None:
        if level not in LEVELS:
            raise ValueError(f"bad alert level {level}")
        req = urllib.request.Request(
            self._url,
            data=message.encode("utf-8"),
            method="POST",
            headers={
                "Title": title.encode("utf-8").decode("latin-1", "replace"),
                "Priority": _PRIORITY[level],
                "Tags": _TAGS[level],
                "Content-Type": "text/plain; charset=utf-8",
            },
        )
        try:
            with urllib.request.urlopen(req, timeout=self._timeout) as r:
                if r.status != 200:
                    raise NtfyError(f"ntfy answered {r.status}")
        except (urllib.error.URLError, OSError, ValueError) as e:
            raise NtfyError(f"ntfy at {self._url}: {e}") from e


class Subscription:
    def __init__(self, bus: AlertBus, size: int = 100) -> None:
        self._bus = bus
        self._q: queue.Queue[Alert] = queue.Queue(maxsize=size)
        self.dropped = 0
        self.closed = False

    def _put(self, a: Alert) -> None:
        if self.closed:
            return
        try:
            self._q.put_nowait(a)
        except queue.Full:
            try:
                self._q.get_nowait()
            except queue.Empty:
                pass
            self.dropped += 1
            self._q.put_nowait(a)

    def get(self, timeout: float) -> Alert | None:
        try:
            return self._q.get(timeout=timeout)
        except queue.Empty:
            return None

    def close(self) -> None:
        self.closed = True
        self._bus._unsubscribe(self)


class _MachineAlerter:
    def __init__(self, bus: AlertBus, machine: str) -> None:
        self._bus, self._machine = bus, machine

    def alert(self, level: str, title: str, message: str) -> None:
        self._bus._publish(level, title, message, self._machine)


class AlertBus:
    """Keeps the last `keep` alerts, wakes subscribers, forwards to `forward` (ntfy)."""

    FORWARD_COMPLAINT_INTERVAL_S = 60.0

    def __init__(self, forward: Alerter | None = None, keep: int = 200) -> None:
        self._forward = forward
        self._recent: deque[Alert] = deque(maxlen=keep)
        self._subs: set[Subscription] = set()
        self._lock = threading.Lock()
        self._next_id = 1
        self._last_complaint = -1e12

    def for_machine(self, name: str) -> Alerter:
        return _MachineAlerter(self, name)

    @property
    def subscribers(self) -> int:
        with self._lock:
            return len(self._subs)

    def recent(self, limit: int = 50) -> list[Alert]:
        with self._lock:
            return list(self._recent)[-limit:]

    def subscribe(self) -> Subscription:
        sub = Subscription(self)
        with self._lock:
            self._subs.add(sub)
        return sub

    def _unsubscribe(self, sub: Subscription) -> None:
        with self._lock:
            self._subs.discard(sub)

    def _publish(self, level: str, title: str, message: str, machine: str, forward: bool = True) -> None:
        if level not in LEVELS:
            raise ValueError(f"bad alert level {level}")
        with self._lock:
            a = Alert(level, title, message, time.time(), machine, self._next_id)
            self._next_id += 1
            self._recent.append(a)
            subs = list(self._subs)
        for s in subs:
            s._put(a)
        if forward and self._forward is not None:
            try:
                self._forward.alert(level, title, message)
            except Exception as e:  # noqa: BLE001 - delivery failure must never reach capture
                now = time.monotonic()
                if now - self._last_complaint >= self.FORWARD_COMPLAINT_INTERVAL_S:
                    self._last_complaint = now
                    self._publish("warning", "Phone alert failed", str(e), machine, forward=False)
```

```python
def cpu_temperature_c() -> float | None:
    """Highest current CPU temperature the OS reports, or None when it reports none

    if not hasattr(psutil, "sensors_temperatures"):
        return None
    temps = psutil.sensors_temperatures()
    readings = [
        e.current
        for name, entries in temps.items()
        if name in ("coretemp", "k10temp", "cpu_thermal", "acpitz", "zenpower")
        for e in entries
        if e.current is not None and 0.0 < e.current < 150.0

    return max(readings) if readings else None

        "cpu_percent": psutil.cpu_percent(interval=None),
        "memory_percent": psutil.virtual_memory().percent,
        "temperature_c": cpu_temperature_c(),
```

```python
"""A Runner keeps one machine alive on its own thread. This plan ships the simulated one;
plans 3 and 4 add a runner for a serial sync box and a Windows camera."""

from __future__ import annotations

import threading
import traceback
from typing import Protocol

from wpcap.config import MachineSpec
from wpcap.machine import Alerter, Machine, MachineConfig
from wpcap.sim.film import SimFilm
from wpcap.sim.rig import SimRig

S = 1_000_000_000


class Runner(Protocol):
    machine: Machine

    def start(self) -> None: ...

    def stop(self) -> None: ...

    @property
    def alive(self) -> bool: ...

    @property
    def error(self) -> str | None: ...


class SimRunner:
    STOP_TIMEOUT_S = 10.0

    def __init__(self, spec: MachineSpec, alerter: Alerter, free_bytes=None) -> None:
        self.spec = spec
        self._alerter = alerter
        config = MachineConfig(
            name=spec.name,
            reel_root=spec.reel_root,
            delay_ms=spec.delay_ms,
            debounce_us=spec.debounce_us,
            gate_min_frames=20,
            gate_empty_needed=8,
        )
        self.rig = SimRig(
            config, self._film(0), alerter=alerter, free_bytes=free_bytes
        )
        self.machine: Machine = self.rig.machine
        self._stop = threading.Event()
        self._thread = threading.Thread(target=self._run, name=f"runner {spec.name}", daemon=True)
        self._error: str | None = None
        self._started = False

    def _film(self, now_ns: int) -> SimFilm:
        return SimFilm(frames=self.spec.sim_frames, start_ns=now_ns + 3 * S)

    def start(self) -> None:
        if self._started:
            raise RuntimeError("runner already started")
        self._started = True
        self._thread.start()

    def _run(self) -> None:
        try:
            while not self._stop.is_set():
                self.rig.run_realtime(0.25)
        except Exception as e:  # noqa: BLE001 - reported, never hidden
            self._error = f"{e}\n{traceback.format_exc()}"
            self._alerter.alert(
                "problem", f"{self.spec.name} capture stopped", f"{e}. Restart the capture program"
            )

    def stop(self) -> None:
        self._stop.set()
        if self._thread.is_alive():
            self._thread.join(self.STOP_TIMEOUT_S)
            if self._thread.is_alive():
                raise RuntimeError(f"runner {self.spec.name} did not stop")
        if self.machine.status().state != "shut_down":
            self.machine.shutdown()

    def restart_film(self) -> None:
        """Demo Mode: thread a fresh simulated reel. Only between reels."""
        with self.machine._lock:  # the rig's thread steps under this lock too
            self.rig.load_film(self._film(self.rig.clock.now_ns()))

    @property
    def alive(self) -> bool:
        return self._thread.is_alive()

    @property
    def error(self) -> str | None:
        return self._error
```

Check `SimRig._step` runs `machine.tick()` under the machine lock: it does not hold it across the whole step, so `restart_film` taking `machine._lock` only guarantees the machine is not mid-event; the rig's `switch_times`/`camera` swap is then safe because the runner thread is the only other reader and reads them in `_step` after `machine.tick()` returns. Ruling: acceptable for Demo Mode; the real runners in plans 3 and 4 have no film to swap.

```python
"""The Service owns everything that runs: machines on their runners, the alert bus, startup
recovery. The web app is a thin view over it."""

from __future__ import annotations

import time
from dataclasses import asdict

from wpcap.alerts import AlertBus, NtfyAlerter
from wpcap.config import AppConfig, MachineSpec
from wpcap.health import pc_health
from wpcap.machine import Machine
from wpcap.recovery import RecoveryReport, recover, repair
from wpcap.reel import ReelFolder
from wpcap.runner import Runner, SimRunner

FRAMES_PER_FOOT = {"super8": 72, "regular8": 80}
DEFAULT_FPS = 18.0


class ServiceError(Exception):
    pass


def _needs_repair(r: RecoveryReport) -> bool:
    return bool(
        r.half_written or r.journal_truncated or r.missing_final_newline or r.corrupt_frames
        or r.orphan_clicks
    )


class Service:
    def __init__(self, config: AppConfig) -> None:
        self.config = config
        forward = NtfyAlerter(config.ntfy) if config.ntfy is not None else None
        self.bus = AlertBus(forward=forward)
        self.runners: dict[str, Runner] = {}
        self.recovery_reports: list[RecoveryReport] = []
        self._started = False
        self._stopped = False

    # ---- lifecycle -------------------------------------------------------------------------

    def start(self) -> None:
        if self._started:
            raise ServiceError("service already started")
        self._started = True
        for spec in self.config.machines:
            if not spec.reel_root.is_dir():
                raise ServiceError(f"reel root for {spec.name} not found: {spec.reel_root}")
        for spec in self.config.machines:
            self._recover_reels(spec)
        for spec in self.config.machines:
            self.runners[spec.name] = self._build_runner(spec)
        started: list[Runner] = []
        try:
            for r in self.runners.values():
                r.start()
                started.append(r)
        except Exception:
            for r in started:
                r.stop()
            raise

    def _build_runner(self, spec: MachineSpec) -> Runner:
        if spec.kind == "sim":
            return SimRunner(spec, self.bus.for_machine(spec.name))
        raise ServiceError(f"machine {spec.name}: unknown kind {spec.kind!r}")

    def _recover_reels(self, spec: MachineSpec) -> None:
        alerter = self.bus.for_machine(spec.name)
        for path in sorted(p for p in spec.reel_root.iterdir() if p.is_dir()):
            if not (path / "journal.jsonl").exists():
                continue
            folder = ReelFolder.open(path)
            report = recover(folder)
            if _needs_repair(report):
                repair(folder, report)
                after = recover(folder)
                alerter.alert(
                    "warning",
                    f"Recovered reel {folder.name}",
                    f"{len(after.complete_frames)} frames kept, "
                    f"{len(report.half_written)} half-written removed, "
                    f"{len(report.corrupt_frames)} corrupt frames flagged, "
                    f"{len(report.orphan_clicks)} orphan clicks closed",
                )
                report = after
            self.recovery_reports.append(report)

    def stop(self) -> None:
        if self._stopped:
            return
        self._stopped = True
        errors = []
        for r in self.runners.values():
            try:
                r.stop()
            except Exception as e:  # noqa: BLE001 - every runner gets its chance to stop
                errors.append(str(e))
        if errors:
            raise ServiceError("; ".join(errors))

    # ---- access ----------------------------------------------------------------------------

    def runner(self, name: str) -> Runner:
        return self.runners[name]  # KeyError for the web layer to turn into 404

    def machine(self, name: str) -> Machine:
        return self.runners[name].machine

    def spec(self, name: str) -> MachineSpec:
        for s in self.config.machines:
            if s.name == name:
                return s
        raise KeyError(name)

    # ---- status ----------------------------------------------------------------------------

    def snapshot(self) -> dict:
        machines = []
        for spec in self.config.machines:
            r = self.runners.get(spec.name)
            if r is None:
                continue
            st = r.machine.status()
            per_foot = FRAMES_PER_FOOT[spec.film_type]
            machines.append(
                {
                    "name": spec.name,
                    "state": str(st.state),
                    "reel": st.reel_name,
                    "segment": st.segment,
                    "saved": st.frames_saved,
                    "failed": st.frames_failed,
                    "pending": st.frames_pending,
                    "clicks": st.clicks,
                    "bounces": st.bounces,
                    "fps": round(st.fps, 1),
                    "sync_error_ms": round(st.sync_error_ms, 3),
                    "free_gb": None if st.free_bytes is None else round(st.free_bytes / 1e9, 1),
                    "feet": round(st.frames_saved / per_foot, 1),
                    "length_s": round(st.frames_saved / DEFAULT_FPS, 1),
                    "delay_ms": r.machine.config.delay_ms,
                    "film_type": spec.film_type,
                    "last_fault": None if st.last_fault is None else asdict(st.last_fault),
                    "warnings": list(st.warnings),
                    "runner_alive": r.alive,
                    "runner_error": r.error,
                }
            )
        return {"t": time.time(), "pc": pc_health(), "machines": machines}
```

|---|---|
| `GET /healthz` | `{"ok": true}`; no auth (for the installer's service check) |
| `POST /api/login` | body `{"password": "..."}`; wrong → sleep 1 s, `401`; right → sets cookie `wpcap_session` (`HttpOnly`, `Secure`, `SameSite=Strict`, 30 days), `{"ok": true}` |
| `POST /api/logout` | clears the cookie |
| `GET /api/status` | `service.snapshot()` |
| `GET /api/events` | server-sent events: `event: status` with the snapshot every 500 ms; `event: alert` with `Alert.as_dict()` as they happen; `event: hello` once with `{"alerts": recent(50)}`; ends when the client disconnects |
| `GET /api/alerts` | `{"alerts": [...recent(50)]}` |
| `GET /api/machines/{name}/live.jpg` | JPEG of `live_picture()`, `404` if none; `Cache-Control: no-store` |
| `GET /api/machines/{name}/last.jpg` | JPEG of `last_saved()`, header `X-Frame-Number` |
| `GET /api/machines/{name}/calibration` | `{"delay_ms": 40.0, "pictures": [{"offset_ms": -33, "url": ".../calibration/0.jpg"}, ...]}` from `click_window(3, 3)`; the pictures are held in a per-machine dict on the app until the next calibration call |
| `GET /api/machines/{name}/calibration/{i}.jpg` | one picture of the last calibration set, `404` if gone |
| `POST /api/machines/{name}/delay` | body `{"delay_ms": 55.0}` → `set_delay_ms`; `ValueError` → `400`, `RuntimeError` → `409` |
| `POST /api/machines/{name}/new-reel` | body `{"name": str|null, "film_type", "notes", "customer", "job_number"}` → `ReelMeta`; `ValueError` (bad name) → `400`; `RuntimeError` (wrong state) → `409`; for a `SimRunner` call `restart_film()` first so the demo has film to scan |
| `POST /api/machines/{name}/stop` | `machine.stop()` |
| `POST /api/machines/{name}/resume` | `machine.resume()`; `RuntimeError` → `409` |
| `GET /` | the static page (Task 8) |

Unknown machine → `404 {"error": "no machine named ..."}`. Every error body is `{"error": "<message>"}`.

```python
from __future__ import annotations

import io

import numpy as np
from PIL import Image


def to_jpeg(pixels: np.ndarray, max_width: int = 640, quality: int = 80) -> bytes:
    im = Image.fromarray(pixels)
    if im.width > max_width:
        im = im.resize((max_width, round(im.height * max_width / im.width)), Image.BILINEAR)
    out = io.BytesIO()
    im.save(out, format="JPEG", quality=quality)
    return out.getvalue()
```

```python
"""Login: one password (scrypt hash in the config) and a signed, expiring session cookie."""

from __future__ import annotations

import hashlib
import hmac
import time

COOKIE = "wpcap_session"
SESSION_DAYS = 30


def make_token(secret: str, issued: float) -> str:
    stamp = f"{int(issued)}"
    sig = hmac.new(secret.encode(), stamp.encode(), hashlib.sha256).hexdigest()
    return f"{stamp}.{sig}"


def check_token(secret: str, token: str, max_age_s: float) -> bool:
    try:
        stamp, sig = token.split(".")
        issued = int(stamp)
    except ValueError:
        return False
    expected = hmac.new(secret.encode(), stamp.encode(), hashlib.sha256).hexdigest()
    if not hmac.compare_digest(expected, sig):
        return False
    return time.time() - issued <= max_age_s
```

```python
"""The web page's API. Thin: every handler reads or pokes the Service and returns."""

from __future__ import annotations

import asyncio
import json
import threading
import time
from pathlib import Path

from fastapi import Depends, FastAPI, HTTPException, Request, Response
from fastapi.responses import FileResponse, JSONResponse, StreamingResponse
from fastapi.staticfiles import StaticFiles
from pydantic import BaseModel, Field

from wpcap.config import AppConfig, verify_password
from wpcap.machine import Machine, ReelMeta
from wpcap.pictures import to_jpeg
from wpcap.runner import SimRunner
from wpcap.service import Service
from wpcap.web.auth import COOKIE, SESSION_DAYS, check_token, make_token

STATIC = Path(__file__).parent / "static"
STATUS_PERIOD_S = 0.5
WRONG_PASSWORD_DELAY_S = 1.0


class LoginBody(BaseModel):
    password: str


class DelayBody(BaseModel):
    delay_ms: float


class NewReelBody(BaseModel):
    name: str | None = None
    film_type: str = "super8"
    notes: str = ""
    customer: str = ""
    job_number: str = ""


def create_app(service: Service, config: AppConfig) -> FastAPI:
    app = FastAPI(title="WorkPrinter Capture", docs_url=None, redoc_url=None, openapi_url=None)
    secret = config.server.secret
    calibration_sets: dict[str, list[bytes]] = {}
    cal_lock = threading.Lock()

    # ---- auth ------------------------------------------------------------------------------

    def require_login(request: Request) -> None:
        token = request.cookies.get(COOKIE)
        if token is None or not check_token(secret, token, SESSION_DAYS * 86400):
            raise HTTPException(401, "login required")

    @app.exception_handler(HTTPException)
    async def _http_error(request: Request, exc: HTTPException):
        return JSONResponse({"error": exc.detail}, status_code=exc.status_code)

    @app.get("/healthz")
    def healthz():
        return {"ok": True}

    @app.post("/api/login")
    async def login(body: LoginBody, response: Response):
        if not verify_password(body.password, config.server.password_hash):
            await asyncio.sleep(WRONG_PASSWORD_DELAY_S)
            raise HTTPException(401, "wrong password")
        response.set_cookie(
            COOKIE,
            make_token(secret, time.time()),
            max_age=SESSION_DAYS * 86400,
            httponly=True,
            secure=True,
            samesite="strict",
        )
        return {"ok": True}

    @app.post("/api/logout")
    def logout(response: Response):
        response.delete_cookie(COOKIE)
        return {"ok": True}

    # ---- status and events -----------------------------------------------------------------

    def machine(name: str) -> Machine:
        try:
            return service.machine(name)
        except KeyError:
            raise HTTPException(404, f"no machine named {name!r}") from None

    @app.get("/api/status", dependencies=[Depends(require_login)])
    def status():
        return service.snapshot()

    @app.get("/api/alerts", dependencies=[Depends(require_login)])
    def alerts():
        return {"alerts": [a.as_dict() for a in service.bus.recent(50)]}

    @app.get("/api/events", dependencies=[Depends(require_login)])
    async def events(request: Request):
        async def gen():
            sub = service.bus.subscribe()
            try:
                hello = {"alerts": [a.as_dict() for a in service.bus.recent(50)]}
                yield f"event: hello\ndata: {json.dumps(hello)}\n\n"
                next_status = 0.0
                while not await request.is_disconnected():
                    now = time.monotonic()
                    if now >= next_status:
                        next_status = now + STATUS_PERIOD_S
                        snap = await asyncio.to_thread(service.snapshot)
                        yield f"event: status\ndata: {json.dumps(snap)}\n\n"
                    alert = await asyncio.to_thread(sub.get, 0.1)
                    while alert is not None:
                        yield f"event: alert\ndata: {json.dumps(alert.as_dict())}\n\n"
                        alert = sub.get(0)
            finally:
                sub.close()

        return StreamingResponse(
            gen(),
            media_type="text/event-stream",
            headers={"Cache-Control": "no-store", "X-Accel-Buffering": "no"},
        )

    # ---- pictures --------------------------------------------------------------------------

    def jpeg(data: bytes, **headers: str) -> Response:
        return Response(data, media_type="image/jpeg", headers={"Cache-Control": "no-store", **headers})

    @app.get("/api/machines/{name}/live.jpg", dependencies=[Depends(require_login)])
    def live(name: str):
        p = machine(name).live_picture()
        if p is None:
            raise HTTPException(404, "no picture from the camera yet")
        return jpeg(to_jpeg(p.pixels))

    @app.get("/api/machines/{name}/last.jpg", dependencies=[Depends(require_login)])
    def last(name: str):
        got = machine(name).last_saved()
        if got is None:
            raise HTTPException(404, "no frame saved yet")
        n, p = got
        return jpeg(to_jpeg(p.pixels), **{"X-Frame-Number": str(n)})

    @app.get("/api/machines/{name}/calibration", dependencies=[Depends(require_login)])
    def calibration(name: str):
        m = machine(name)
        window = m.click_window(3, 3)
        pics = [to_jpeg(p.pixels) for _, p in window]
        with cal_lock:
            calibration_sets[name] = pics
        return {
            "delay_ms": m.config.delay_ms,
            "pictures": [
                {"offset_ms": off, "url": f"/api/machines/{name}/calibration/{i}.jpg"}
                for i, (off, _) in enumerate(window)
            ],
        }

    @app.get("/api/machines/{name}/calibration/{i}.jpg", dependencies=[Depends(require_login)])
    def calibration_picture(name: str, i: int):
        machine(name)
        with cal_lock:
            pics = calibration_sets.get(name, [])
            if not 0 <= i < len(pics):
                raise HTTPException(404, "calibration picture gone; fetch calibration again")
            return jpeg(pics[i])

    # ---- actions ---------------------------------------------------------------------------

    def act(fn):
        try:
            return fn()
        except ValueError as e:
            raise HTTPException(400, str(e)) from None
        except RuntimeError as e:
            raise HTTPException(409, str(e)) from None

    @app.post("/api/machines/{name}/delay", dependencies=[Depends(require_login)])
    def set_delay(name: str, body: DelayBody):
        m = machine(name)
        act(lambda: m.set_delay_ms(body.delay_ms))
        return {"ok": True, "delay_ms": m.config.delay_ms}

    @app.post("/api/machines/{name}/new-reel", dependencies=[Depends(require_login)])
    def new_reel(name: str, body: NewReelBody):
        m = machine(name)
        runner = service.runner(name)
        meta = ReelMeta(
            name=body.name or None,
            film_type=body.film_type,
            notes=body.notes,
            customer=body.customer,
            job_number=body.job_number,
        )

        def go():
            if isinstance(runner, SimRunner):
                runner.restart_film()
            m.new_reel(meta)

        act(go)
        return {"ok": True, "reel": m.reel.name}

    @app.post("/api/machines/{name}/stop", dependencies=[Depends(require_login)])
    def stop(name: str):
        act(machine(name).stop)
        return {"ok": True}

    @app.post("/api/machines/{name}/resume", dependencies=[Depends(require_login)])
    def resume(name: str):
        act(machine(name).resume)
        return {"ok": True}

    # ---- page ------------------------------------------------------------------------------

    @app.get("/")
    def index():
        return FileResponse(STATIC / "index.html", headers={"Cache-Control": "no-store"})

    app.mount("/static", StaticFiles(directory=STATIC), name="static")
    return app
```

```javascript
}
```

```python
"""A tiny local certificate authority so the page can be HTTPS on a home network."""

from __future__ import annotations

import datetime as dt
import ipaddress
import os
import socket
from pathlib import Path

from cryptography import x509
from cryptography.hazmat.primitives import hashes, serialization
from cryptography.hazmat.primitives.asymmetric import ec
from cryptography.x509.oid import ExtendedKeyUsageOID, NameOID


def _write_private(path: Path, key: ec.EllipticCurvePrivateKey) -> None:
    if path.exists():
        raise FileExistsError(path)
    pem = key.private_bytes(
        serialization.Encoding.PEM,
        serialization.PrivateFormat.PKCS8,
        serialization.NoEncryption(),
    )
    fd = os.open(path, os.O_WRONLY | os.O_CREAT | os.O_EXCL, 0o600)
    with os.fdopen(fd, "wb") as f:
        f.write(pem)


def _write_cert(path: Path, cert: x509.Certificate) -> None:
    if path.exists():
        raise FileExistsError(path)
    path.write_bytes(cert.public_bytes(serialization.Encoding.PEM))


def make_local_ca(out_dir: Path, name: str = "WorkPrinter Capture Local CA") -> tuple[Path, Path]:
    out_dir.mkdir(parents=True, exist_ok=True)
    ca_crt, ca_key = out_dir / "ca.crt", out_dir / "ca.key"
    if ca_crt.exists() or ca_key.exists():
        raise FileExistsError(f"{ca_crt} or {ca_key} already exists")
    key = ec.generate_private_key(ec.SECP256R1())
    subject = x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, name)])
    now = dt.datetime.now(dt.UTC)
    cert = (
        x509.CertificateBuilder()
        .subject_name(subject)
        .issuer_name(subject)
        .public_key(key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(now - dt.timedelta(minutes=5))
        .not_valid_after(now + dt.timedelta(days=3650 * 2))
        .add_extension(x509.BasicConstraints(ca=True, path_length=0), critical=True)
        .add_extension(
            x509.KeyUsage(
                digital_signature=True, key_cert_sign=True, crl_sign=True, content_commitment=False,
                key_encipherment=False, data_encipherment=False, key_agreement=False,
                encipher_only=False, decipher_only=False,
            ),
            critical=True,
        )
        .add_extension(x509.SubjectKeyIdentifier.from_public_key(key.public_key()), critical=False)
        .sign(key, hashes.SHA256())
    )
    _write_private(ca_key, key)
    _write_cert(ca_crt, cert)
    return ca_crt, ca_key


def make_server_cert(
    ca_cert: Path,
    ca_key: Path,
    out_cert: Path,
    out_key: Path,
    hostnames: list[str],
    ips: list[str],
    days: int = 3650,
) -> None:
    if out_cert.exists() or out_key.exists():
        raise FileExistsError(f"{out_cert} or {out_key} already exists")
    ca = x509.load_pem_x509_certificate(ca_cert.read_bytes())
    signer = serialization.load_pem_private_key(ca_key.read_bytes(), password=None)
    key = ec.generate_private_key(ec.SECP256R1())
    now = dt.datetime.now(dt.UTC)
    names: list[x509.GeneralName] = [x509.DNSName(h) for h in hostnames]
    names += [x509.IPAddress(ipaddress.ip_address(ip)) for ip in ips]
    cert = (
        x509.CertificateBuilder()
        .subject_name(x509.Name([x509.NameAttribute(NameOID.COMMON_NAME, hostnames[0])]))
        .issuer_name(ca.subject)
        .public_key(key.public_key())
        .serial_number(x509.random_serial_number())
        .not_valid_before(now - dt.timedelta(minutes=5))
        .not_valid_after(now + dt.timedelta(days=days))
        .add_extension(x509.BasicConstraints(ca=False, path_length=None), critical=True)
        .add_extension(x509.SubjectAlternativeName(names), critical=False)
        .add_extension(x509.ExtendedKeyUsage([ExtendedKeyUsageOID.SERVER_AUTH]), critical=False)
        .add_extension(
            x509.AuthorityKeyIdentifier.from_issuer_public_key(ca.public_key()), critical=False
        )
        .sign(signer, hashes.SHA256())
    )
    out_cert.parent.mkdir(parents=True, exist_ok=True)
    _write_private(out_key, key)
    _write_cert(out_cert, cert)


def local_names() -> tuple[list[str], list[str]]:
    """Hostnames and IPv4 addresses this PC answers to, for the certificate."""
    host = socket.gethostname()
    hosts = [host, "localhost"]
    ips: list[str] = []
    try:
        for info in socket.getaddrinfo(host, None, socket.AF_INET):
            ip = info[4][0]
            if not ip.startswith("127.") and ip not in ips:
                ips.append(ip)
    except socket.gaierror:
        pass
    if "127.0.0.1" not in ips:
        ips.append("127.0.0.1")
    return hosts, ips
```

The `except socket.gaierror: pass` is deliberate: a PC whose hostname does not resolve still gets a certificate for `localhost` and `127.0.0.1`; the Tailscale and LAN addresses are added by the operator with `wpcap gen-cert --ip` (Task 10). State this in the docstring.
